# Quality standards for the team

A task is Done when:
- Diagrams match the Class Diagram attributes (e.g., UUID, OrderStatus).
- The component is mapped in the Traceability Matrix.
- At least one peer has reviewed the work.
- The GitHub Issue is closed and moved to "Done".

During M3:
- Core Logic: All business rules from the SRS and M2 are fully implemented in the Service layer.
- API Standard: Endpoints are RESTful, documented via FastAPI, and handle errors (400, 401, 403, 404) correctly.
Testing:
- Both unit and integration tests are present for every module.
- Tests pass successfully in the GitHub Actions CI environment.
- Review: At least one teammate has reviewed and approved the pull request.
- Traceability: The Traceability Matrix in docs/ is updated to link the code to its corresponding M1 requirement.
